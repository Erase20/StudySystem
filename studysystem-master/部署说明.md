# 在线学习管理系统 - 部署说明

## 一、环境要求

| 环境       | 版本要求              | 说明                         |
| ---------- | --------------------- | ---------------------------- |
| JDK        | 1.8+                  | 后端运行环境                 |
| Maven      | 3.6+                  | 后端依赖管理与构建           |
| Node.js    | 14.x ~ 16.x           | 前端运行环境                 |
| MySQL      | 5.7+ / 8.0+           | 数据库                       |
| Python     | 3.8+（可选）          | 仅用于运行数据生成脚本       |

## 二、数据库初始化

### 2.1 创建数据库

```sql
CREATE DATABASE IF NOT EXISTS manager DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

### 2.2 导入表结构

按顺序执行以下 SQL 文件：

```bash
mysql -u root -p manager < springboot/src/main/resources/manager.sql
mysql -u root -p manager < springboot/src/main/resources/learning_center.sql
```

### 2.3 导入演示数据

```bash
mysql -u root -p manager < springboot/src/main/resources/fresh_demo_data.sql
```

### 2.4 生成聚类用户数据（可选）

如需生成500条聚类用户数据（含演示账号 demo/123456）：

```bash
cd spider
pip install -r requirements.txt
python gen_users.py
```

> 注意：运行前确保 `course` 表中已有课程数据，脚本会先查询实际课程ID再使用。

### 2.5 修改数据库连接

编辑 `springboot/src/main/resources/application.yml`，修改数据库用户名和密码：

```yaml
spring:
  datasource:
    username: root     # 改为你的数据库用户名
    password: root     # 改为你的数据库密码
```

## 三、后端启动

```bash
cd springboot
mvn spring-boot:run
```

启动成功后，后端服务运行在 `http://localhost:9090`。

## 七、常见问题

### Q1：后端启动报错 "Access denied for user"

检查 `application.yml` 中的数据库用户名和密码是否正确。

### Q2：前端启动报错 "npm ERR! code ERESOLVE"

Node.js 版本可能过高，建议使用 14.x ~ 16.x。或使用：

```bash
npm install --legacy-peer-deps
```

### Q3：前端页面显示空白或接口404

确保后端已在 `9090` 端口启动。前端通过代理将 `/api` 请求转发到后端。

### Q4：图片/视频无法显示

上传的文件存储在 `files/` 目录下，后端通过 `/files/` 路径提供静态文件访问。确保该目录存在且有读写权限。

### Q5：端口被占用

- 后端默认端口 `9090`，可在 `application.yml` 中修改 `server.port`
- 前端默认端口 `8080`，可在 `vue.config.js` 中修改 `devServer.port`

## 八、生产环境打包

### 前端打包

```bash
cd vue
npm run build
```

生成的静态文件在 `vue/dist/` 目录，可部署到 Nginx 等 Web 服务器。

### 后端打包

```bash
cd springboot
mvn clean package -DskipTests
```

生成的 JAR 文件在 `springboot/target/` 目录，可通过以下命令运行：

```bash
java -jar target/springboot-0.0.1-SNAPSHOT.jar
```
