# 在线学习管理系统 - 启动指南

## 一、环境要求

1. **Node.js** (推荐 v14+)
2. **MySQL** (推荐 v5.7+)
3. **JDK** (推荐 v1.8+)
4. **Maven** (用于构建后端)

## 二、后端启动步骤

### 1. 初始化数据库

打开MySQL客户端，执行以下命令：

```sql
-- 创建数据库
CREATE DATABASE IF NOT EXISTS manager CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 使用数据库
USE manager;

-- 导入数据库结构（如果有的话）
-- source /path/to/manager.sql;

-- 导入演示数据
source d:/Project/studysystem-master/studysystem-master/springboot/src/main/resources/demo_data.sql;
```

### 2. 修改数据库配置（如果需要）

编辑 `springboot/src/main/resources/application.yml`，确保数据库用户名密码正确：

```yaml
spring:
  datasource:
    username: root   # 修改为你的数据库用户名
    password: root   # 修改为你的数据库密码
    url: jdbc:mysql://localhost:3306/manager?useUnicode=true&characterEncoding=utf-8&allowMultiQueries=true&useSSL=false&serverTimezone=GMT%2b8&allowPublicKeyRetrieval=true
```

### 3. 启动后端服务

```bash
cd d:/Project/studysystem-master/studysystem-master/springboot

# 如果使用Maven Wrapper (推荐)
mvnw.cmd spring-boot:run

# 或者先打包再运行
mvn clean package -DskipTests
java -jar target/springboot-0.0.1-SNAPSHOT.jar
```

后端启动后运行在 http://localhost:9090

## 三、前端启动步骤

```bash
cd d:/Project/studysystem-master/studysystem-master/vue

# 安装依赖（如果还没有）
npm install

# 启动开发服务器
npm run serve
```

前端启动后运行在 http://localhost:8080

## 五、常见问题

### 1. 登录提示"网络错误"
- 检查后端服务是否启动：访问 http://localhost:9090
- 检查数据库是否运行
- 检查数据库是否已导入演示数据

### 2. 图片不显示
- 如果是课程图片，检查课程数据是否已导入
- 如果是本地图片，检查files目录是否存在
- 如果是外部图片链接，检查网络连接

### 3. 编译错误
- 删除node_modules目录
- 重新安装依赖：npm install

### 4. 端口被占用
- 修改vue.config.js中的端口
- 或修改application.yml中的端口
